# UNO 规则说明（本项目所用版本）

本项目采用**精简版 108 张牌组**，去掉了容易产生争议的变体规则，其余机制与经典 UNO 一致。

## 一、目标

先把自己手上的牌全部打出的人获胜。一局定胜负，不计分。

## 二、开局

1. 洗牌后每人发 **7 张**牌，其余牌背面朝上作为摸牌堆。
2. 从摸牌堆翻开一张作为起始牌，放在弃牌堆。
3. 起始牌**一定是数字牌**：如果翻到功能牌或万能牌，会把这张牌压到牌堆底部，重新翻一张。

## 三、每回合怎么做

1. 打出一张与弃牌堆顶牌**同色、同数字或同符号**的牌。
2. 没有能打的牌时，从摸牌堆摸一张。摸到的牌如果刚好能打，**可以选择立刻打出，也可以留着直接结束回合**（官方原文为 *you are free to put it down*）。
3. 打出功能牌后，效果立刻结算，然后轮到下一位玩家。
4. 万能牌任何时候都可以打（变色 +4 有额外限制，见下）。

## 四、牌型与效果

| 牌型 | 数量 | 效果 |
| --- | --- | --- |
| 数字牌 0–9 | 每色 19 张（0 一张，1–9 各两张） | 无特殊效果，按颜色或数字接牌 |
| 跳过 Skip | 每色 2 张 | 下一位玩家失去本回合 |
| 反转 Reverse | 每色 2 张 | 出牌方向倒转；两人对局时等同于「跳过」 |
| 抽两张 +2 | 每色 2 张 | 下一位玩家摸 2 张，并失去本回合 |
| 变色 Wild | 共 4 张 | 指定接下来的颜色，下一位玩家照常出牌 |
| 变色 +4 | 共 4 张 | 指定颜色，下一位玩家摸 4 张并失去回合；手上还有当前颜色的牌时**不能出** |

四色各 25 张（19 张数字 + 3 种功能牌各 2 张）共 100 张，加 8 张万能牌，总计 **108 张**。

## 五、本版本的特别约定

| 规则 | 处理方式 |
| --- | --- |
| 起始牌 | 强制为数字牌，翻到功能牌或万能牌则压回牌堆重翻 |
| 两人局反转 | 等同于「跳过」，不翻转方向，避免方向反复横跳 |
| 摸牌后可出可过 | 摸到的牌能打时，由玩家自行决定是否打出 |
| 叠牌（+2 叠 +2、+4 接力） | **不采用**。+2 就是摸 2 张，不能用功能牌顶回去 |
| 质疑 +4 | **不采用**。改为界面直接禁止不合规打出：手上有当前颜色时该牌置灰、点不动 |
| 换手牌 / 洗牌重发 / 自定规则牌 | **不采用**，交互链路过长且难以判定 |
| 7-0 规则 | **不采用** |
| UNO 喊话 | **不采用**。剩最后一张不必宣告，也不会被罚牌 |
| 500 分多轮计分 | **不采用**。一局定胜负 |
| 出牌倒计时 | **不采用** |

## 六、操作提示

- 能打的牌会向上浮起并加深阴影，不能打的牌变灰且点不动。
- 点击浮起的牌即出牌；打出万能牌会弹出四色面板，选完颜色才真正生效。
- 轮到你却无牌可出时，点左侧的摸牌堆摸牌。
- 右上角「对局日志」记录每一步谁打了什么牌。
- 顶栏「规则说明」随时可以调出本页内容的界面版本。

## 七、实现约定（开发者参考）

- 所有判定逻辑集中在 `shared/rules.js`，为纯函数，前后端共用同一份，服务端是唯一权威状态源。
- 牌组生成在 `shared/deck.js`，随机源可注入，同一随机种子可完整复现同一局牌序。
- 弃牌堆回收时保留最上一张，用 `seed + reshuffleCount` 生成确定性随机源，保证对局可重放。
- 更细节的边界情况（如摸牌堆耗尽、最后一张为功能牌）由 `tests/` 下的单元测试与自对弈压力测试覆盖。
